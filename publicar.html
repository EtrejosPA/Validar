1Conexión con GitHub

Se hace una sola vez en este navegador. La clave queda guardada solo aquí.

¿Cómo obtengo la clave?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: Publicador LEAN. Expiración: la que prefieras (por ejemplo, 1 año).
  3. Repository access → Only select repositories → Validar.
  4. Permissions → Contents → Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.
